# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - Initial Archival Release

### Added
- City traffic network represented as a weighted, directed graph
- Vehicle routing system using Dijkstra's Algorithm
- Traffic signal management with priority queues
- Congestion monitoring using BFS/DFS
- Emergency vehicle handling with special routing
- Accident and road closure simulation
- CSV file parsing for road network, vehicles, and traffic data

### Data Structures
- Graph with adjacency lists
- Priority Queue
- Min-Heap
- Hash Table for congestion tracking
- Custom Vector, LinkedList, Queue, and Stack implementations
